# 微信粘贴兼容说明

当前渲染器输出语义简单、内联样式的 HTML；剪贴板同时携带纯文本兼容表示，但不提供单独的纯文本复制入口。HTTPS/localhost 优先使用剪贴板 API，普通 HTTP、接口不可用或写入失败时通过选区与 `copy` 事件兼容复制同一份 HTML。图片仅输出 HTTPS 地址；无公网 HTTPS 地址或尚未经过公众号后台实测的图片会提示手动检查。图片资源失效时复制内容改为补图占位，并可从浏览器保存的原图重新上传。

已在 Chrome 无头浏览器中通过真实系统剪贴板粘贴到 `contenteditable`，验证安全上下文、普通 HTTP、剪贴板权限错误与缺少 `ClipboardItem` 的路径均保留内联样式、加粗语义和 HTTPS 图片地址；另已验证双路径失败后的清理与 HTML 重试，以及超长标题确认。尚未在 135 编辑器或公众号后台执行“复制 → 粘贴 → 保存草稿 → 重开”的实际回归。浏览器验证通过不代表目标编辑器最终保留了样式或成功转存图片。

目前所有模板的 `status` 保持 `draft`。完成真实后台回归后，再按 `docs/compat-report.md` 记录结果并更新状态。
