# 微信粘贴兼容说明

当前渲染器输出语义简单、内联样式的 HTML 与纯文本双格式。图片仅输出 HTTPS 地址；无公网 HTTPS 地址或尚未经过公众号后台实测的图片会提示手动检查。图片资源失效时复制内容改为补图占位，并可从浏览器保存的原图重新上传。

本环境没有可用公众号后台账号，也没有可访问的浏览器自动化运行环境，因此没有执行“复制 → 粘贴 → 保存草稿 → 重开”的实际回归。本地浏览器剪贴板成功只代表浏览器写入成功，不代表公众号后台保留了样式或图片。

目前所有模板的 `status` 保持 `draft`。完成真实后台回归后，再按 `docs/compat-report.md` 记录结果并更新状态。
