# 模板 v2：设计与内容适配

## 设计参考

本轮搜索参考的是风格方向与信息层级，未复制第三方模板代码、图片、字体或付费素材。

- [135 编辑器：复古风格](https://www.135editor.com/moban/fugu.html)：纸页、书卷、胶片、复古配色等方向。
- [135 编辑器：杂志期刊](https://www.135editor.com/moban/zazhi/qikan.html)：刊头、章节、图文层级与连续阅读。
- [青排：模板库](https://qingpaitools.com/templates)：按风格、内容目标和用途组织模板。
- [Mailchimp：Layout and Purpose](https://templates.mailchimp.com/design/layout-and-purpose/)：布局服从内容目的，移动端优先。
- [Mailchimp：Typography](https://templates.mailchimp.com/design/typography/)：使用系统字体回退，不能依赖外部字体才能成立。
- [NN/g：Chunking](https://www.nngroup.com/articles/chunking/)：标题、内容分组和视觉层级共同帮助扫读。

## 内容与视觉的边界

AI 定制排版是独立于正文生成的新流程：在右侧模板区选择「根据内容设计」或「按我的要求设计」，只将完整语义内容和可选风格描述交给模型。模型输出新布局树、各类型默认样式和逐块样式，不读取原模板、颜色、字体或手动强调。所有内容通过原始ID按原顺序引用一次，程序填入全文，禁止重写和遗漏。原文排版也可显式使用此功能，文字保留规则不变。

`layout-design.js` 共享设计Schema和完整性、字号、对比度及留白校验；`layout-renderer.js` 将有限深度的原创分组和样式编译为允许的标签与内联CSS，再由共同渲染器检查。生成结果还要经过浏览器320/375/414px溢出检查，才进入主预览区试用；应用后保存至文章 `layoutDesign`。取消恢复原排版，应用支持现有撤销，模板库缩略图继续准确展示各自固定模板。内容结构变化时保留全部当前内容和顺序，沿用逐块样式及分组的前景背景色，提示重新设计分组。应用时清理旧手动视觉样式，原始文章由撤销保留；应用后新增的文字、段落和图片手动调整继续同步预览与复制。

`content.js` 将模型返回整理为八种语义块。AI 可以表达加粗重点，但不能指定颜色、字号、字体、HTML、CSS 或模板 ID。JSON 围栏、Markdown 正文、文字型段落和清单条目会转换成统一结构；长段落按句子拆分，保留文字与行内重点。正文不能为空，无效图片、未知块类型或超出约束的输出会触发重试。一次失败的未校验草稿不会被误接纳。

`renderer.js` 是预览与复制的共同渲染器。刊头、导读、章节标题、目录、清单、引用、图文、强调方式与页尾都来自模板。正文连续排列，不再按章节套卡片或独立底色；预览和复制使用相同排版。模板切换不修改文章事实、段落顺序或内容块。没有摘要、章节、引文或图片时不强凑模块；内容索引只从现有章节生成，装饰不能伪造作者、期号、数据或引用。

全部模板不再自动添加“图 01、图 02”等图片编号。图片标题和说明只使用内容块中已有的用户文字；两者均为空时省略说明容器、色条和额外间距。新插入的本地或链接图片默认图注为空，正文、预览和复制保持一致。

原文排版继续使用 `rawparser.js` 和文字一致性检查，不调用生成规范化逻辑改写原文。Markdown 的二、三级标题区分为章节和子节。

## 选模与再生成

- 首次生成后，按主题、实际字数、章节、列表、引用、重点块与图片数选择初始模板；推荐保留三个不同系列。
- 模板卡片使用当前文章的开篇内容和真实图片，完整试用区展示整篇文章。取消恢复原模板，确认才写入文章的 `templateId`。
- 重新生成携带已选模板。服务端只将该模板的语义偏好传给 AI，提醒缺少素材时省略，不让 AI 输出样式或为版式编造事实。
- 推荐和适配说明根据当前内容实时计算，无图片的文章也能使用全部模板。

## 兼容范围

输出使用 `section / p / span / strong / br / img` 与允许的内联样式，不依赖脚本、外部字体、复杂定位或第三方装饰资源。预览 iframe 保持禁止脚本，并使用同源访问权限支持文档更新与滚动恢复。

按用户要求，本轮不新增或运行测试套件，不执行浏览器和公众号后台回归；仅保留必要的编译检查。真实公众号粘贴、保存、重开仍按 `compat-report.md` 单独记录，不能把本地排版完成视作公众号实测通过。
