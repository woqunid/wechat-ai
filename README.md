# Weave 公众号内容工作台

本地 Web 应用：输入主题或素材，生成文章草稿，编辑内容、切换 40 套模板，并复制微信兼容的富文本。AI 设置可选择部署方通过 `.env` 统一提供的平台 AI，或由用户保存在当前浏览器的个人 AI。

编辑页模板区新增「AI 定制排版」，可选择根据全文设计或按个人风格要求设计。全文送交 AI 时去掉原视觉样式，保留全部文字、顺序、引用和图片；独立生成布局与样式，不限于40套预设。通过完整性、可读性及320/375/414px适配检查后先试用，再应用、保存和复制，支持撤销。需要已配置的 AI 服务，新增 `/api/articles/design` 后需重启后端。

模板 v2 提供杂志、复古纸页、手账、科技档案、商务报告、活动票券、国风与品牌画册等方向。模板库直接展示当前文章，支持风格检索、完整正文试用和取消恢复。AI 只输出语义内容，服务端整理 Markdown、标题层级、清单与长段落，模板统一决定视觉版式；重新生成保留所选模板。设计参考与适配规则见 [docs/template-design.md](docs/template-design.md)。

编辑页以整篇内联 HTML 为内容和版式保存源，旧草稿首次打开时按原模板或独立版式转换。AI 可直接调整分组、列表内部间距、边框、留白及图文结构；画布支持直接输入、常用格式工具栏、图片增删替换、拖放、宽度和对齐设置。预览和复制读取同一份 HTML，编辑标记不进入复制结果，不提供源码编辑入口。撤销、重做和草稿恢复保留完整 HTML；切换模板先展示全文预览，确认后替换当前版式。

编辑页可通过“保存历史”手动保存当前正文和完整样式，历史列表支持查看/修改和删除；同一篇文章再次保存会更新原记录。历史保存在当前浏览器的 IndexedDB，不包含 AI 对话、附件和撤销记录；从最近一次手动保存起保留 30 天，页面打开期间、重新进入应用或读取列表时自动清理到期记录。图片按上传时间保留 30 天，清空当前草稿不会提前删除历史文章引用的服务端图片。

创作表单在成功生成或原文排版进入编辑后清空，原始素材随文章保存，继续用于重新生成；生成失败则保留输入。编辑页返回“新建文章”会先保存当前草稿，再显示空白创作表单，首页刷新仍留在首页；编辑页刷新直接恢复该文章。首页“未完成草稿”支持多篇文章继续编辑和单篇删除，草稿从最近一次内容修改起保留 30 天，读取、打开或返回首页不会续期，到期清理对应 AI 附件。旧版单篇草稿会迁入列表，从升级时开始计时，首次升级默认留在首页。草稿、页面位置和手动历史均仅保存在当前浏览器；图片保留 30 天。

格式工具栏根据选区回显字号、颜色、加粗、下划线、段落类型及对齐状态，混合格式显示“多种”，并分别提示文字与段落的修改范围。字号、行距、段前后间距、左右缩进和字间距支持手动输入，失焦或回车后应用，Esc 取消输入。先“复制格式”，再选择目标并“应用格式”，可复制共有的文字及段落样式，混合项保留目标原样式；“清除文字样式”用于选中文字，“恢复正文格式”用于将选中段落还原为正文并重置样式，均支持撤销。

右侧「AI修改」仍读取全文。选中文字或图片会添加引用卡片，预览方案时引用当前方案内容。AI 结合本次要求、引用和对话自动决定修改位置：优先局部调整，明确要求时才整体重排；没有选区时直接定位对应段落，连续指令沿用最近有效修改目标。候选方案与原稿切换对比，支持逐处撤回、换一个方案、画布取消；默认确认后应用，也可勾选校验通过后直接应用，均支持撤销。生成期间按 HTML 节点合并无关手动编辑，冲突则拒绝覆盖。只要求排版时保留原文，继续检查对比度及320/375/414px适配；溢出时携带检测结果自动修正一次，不支持的样式会纠正或明确提示已忽略。失败或停止可在原消息重试，不重复加入对话；撤销后同步更新方案状态。

对话可通过附件按钮或在输入框直接粘贴图片、PDF、DOCX、TXT、MD 作为参考，也可通过链接按钮添加图床图片；要求“把图片放到合适位置”时，支持识图的模型会按画面内容把附件图片插入正文；截图可直接 Ctrl+V 上传，普通文字及图文混合粘贴仍保留文字输入；附件按文章缓存在本地，聊天与选区卡片仅保存在当前编辑会话。文本型文档提取文字，DOCX/PDF 内嵌图片交给支持识图的模型，扫描版 PDF 不做 OCR。新增或更新 AI 接口后需重启后端。

创作、润色分别使用明确规则，正式/通俗/活泼语气影响表达，模板只控制视觉。正文目标范围为 ±15%，生成后实测并最多纠正一次；润色优先保留事实，无法达标时保留可用正文，不强行截断。编辑页持续显示字数，AI 重新生成沿用该文章的原始输入、设置、当前图片与所选模板。原文排版绕过 AI，仍可手动编辑。

编辑器图片按钮直接打开插图弹窗，支持选择本地素材、上传图片或读取公网 HTTPS 图片直链后确认插入。正文单独粘贴链接会先保留文字，再识别并转换为图片，失败不丢文字。链接图片缓存为标准素材，继续参与模板预览、草稿恢复、AI 再生成及公众号复制；新增 `/api/assets/import` 后需重启后端。服务端所在网络无法直连图床（如 postimg.cc）时，在 `.env` 设置 `HTTPS_PROXY=http://127.0.0.1:端口` 并重启后端，`NO_PROXY` 可排除不走代理的域名。

## 开发

需要 Node.js 20.19+ 或 22.12+。

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

前端运行于 `http://localhost:5173`，API 运行于 `http://localhost:8787`。平台 AI 管理页为 `/baolongadmin`，访问密码由部署环境中的 `BAOLONG_ADMIN_PASSWORD` 提供；页面保存的模型地址、密钥和模型写入项目根目录 `.env` 并立即生效。个人 AI 设置保存在用户当前浏览器的本地存储中，发起模型请求时会临时发送到应用服务，不写入服务端配置文件。未配置可用 AI 时，创作、AI 修改、重新生成和定制排版会提示用户完成配置。复制会保留 HTML 排版，可粘贴到 135 编辑器或公众号后台；HTTPS 或 localhost 优先使用剪贴板 API，普通 HTTP 或接口不可用时尝试浏览器兼容复制。

局域网访问使用 Vite 输出的 Network 地址。开发代理保留页面 Host，并传递原始地址与协议；通过前端的 `/api` 访问时，不需要将每次变化的局域网 IP 加入 `ALLOWED_ORIGIN`。修改 `vite.config.js` 后需重启开发服务。前后端分属不同来源时，仍需将前端完整地址加入 `ALLOWED_ORIGIN` 并重启后端。

验证使用 `npm test` 和 `npm run build`。接口测试使用隔离的本地模型响应，不改写现有 AI 配置，也不会调用真实模型。

## 生产启动

```powershell
npm run build
npm start
```

生产启动前应设置部署环境变量 `BAOLONG_ADMIN_PASSWORD`，并执行构建；首次通过 `/baolongadmin` 保存平台 AI 配置时会自动创建或更新根目录 `.env`，服务需要对该文件所在目录有写入权限。若 AI 配置已存在，也可随部署提供 `.env`。Express 同时提供 `dist/`、图片资源和 API。`ASSET_DIR` 用于图片持久化，新增图片统一按北京时间的上传日期存入 `YYYY-MM-DD/` 子目录，根目录旧图片和旧链接继续可用。图片默认保留 30 天，`ASSET_TTL_DAYS` 可延长保留期，低于 30 天的值按 30 天处理。服务启动及每隔 24 小时检查一次，仅删除按文件保存时间已满保留期的图片，并移除空的日期目录，不按目录日期整批删除。`PUBLIC_BASE_URL` 配置可被公众号访问的 HTTPS 图片主机；留空时使用当前站点地址，复制结果会将非 HTTPS 图片替换为补图占位。

接口列表、错误码见 [docs/api.md](docs/api.md)。真实公众号后台粘贴回归和限制见 [docs/known-limitations.md](docs/known-limitations.md)。
