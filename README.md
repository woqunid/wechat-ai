# Weave 公众号内容工作台

本地 Web 应用：输入主题或素材，生成文章草稿，编辑内容、切换 40 套模板，并复制微信兼容的富文本。创作页与编辑页均可在“AI 服务”中填写 OpenAI 兼容 URL、获取模型并保存配置。

编辑页模板区新增「AI 定制排版」，可选择根据全文设计或按个人风格要求设计。全文送交 AI 时去掉原视觉样式，保留全部文字、顺序、引用和图片；独立生成布局与样式，不限于40套预设。通过完整性、可读性及320/375/414px适配检查后先试用，再应用、保存和复制，支持撤销。需要已配置的 AI 服务，新增 `/api/articles/design` 后需重启后端。

模板 v2 提供杂志、复古纸页、手账、科技档案、商务报告、活动票券、国风与品牌画册等方向。模板库直接展示当前文章，支持风格检索、完整正文试用和取消恢复。AI 只输出语义内容，服务端整理 Markdown、标题层级、清单与长段落，模板统一决定视觉版式；重新生成保留所选模板。设计参考与适配规则见 [docs/template-design.md](docs/template-design.md)。

编辑页以整篇内联 HTML 为内容和版式保存源，旧草稿首次打开时按原模板或独立版式转换。AI 可直接调整分组、列表内部间距、边框、留白及图文结构；画布支持直接输入、常用格式工具栏、图片增删替换、拖放、宽度和对齐设置。预览和复制读取同一份 HTML，编辑标记不进入复制结果，不提供源码编辑入口。撤销、重做和草稿恢复保留完整 HTML；切换模板先展示全文预览，确认后替换当前版式。

右侧「AI修改」仍读取全文。选中文字或图片会添加选区卡片，默认只允许修改选区，可手动切换到全文；局部文字替换保留边界外的内容与样式。只要求排版时校验原文字序不变，明确要求改写时允许内容修改。候选方案先在画布展示，与原稿切换对比，点击“应用修改”后才保存；生成期间正文变化则拒绝覆盖。HTML 过滤仅允许单列流式排版、内联样式和已登记图片，生成方案继续执行对比度及320/375/414px适配检查。

对话可附加图片、PDF、DOCX、TXT、MD 作为参考；附件按文章缓存在本地，聊天与选区卡片仅保存在当前编辑会话。文本型文档提取文字，DOCX/PDF 内嵌图片交给支持识图的模型，扫描版 PDF 不做 OCR。新增或更新 AI 接口后需重启后端。

创作、润色分别使用明确规则，正式/通俗/活泼语气影响表达，模板只控制视觉。正文目标范围为 ±15%，生成后实测并最多纠正一次；润色优先保留事实，无法达标时保留可用正文，不强行截断。编辑页持续显示字数，AI 重新生成沿用该文章的原始输入、设置、当前图片与所选模板。原文排版绕过 AI，仍可手动编辑。

编辑器图片按钮直接打开插图弹窗，支持选择本地素材、上传图片或读取公网 HTTPS 图片直链后确认插入。正文单独粘贴链接会先保留文字，再识别并转换为图片，失败不丢文字。链接图片缓存为标准素材，继续参与模板预览、草稿恢复、AI 再生成及公众号复制；新增 `/api/assets/import` 后需重启后端。

## 开发

需要 Node.js 20.19+ 或 22.12+。

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

前端运行于 `http://localhost:5173`，API 运行于 `http://localhost:8787`。未配置 AI 服务时使用本地示例内容；可以在页面“AI 服务”中配置，也可以在 `.env` 中设置 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL`。页面配置保存在服务端 `.local/ai-config.json`，密钥不会进入浏览器存储。复制会保留 HTML 排版，可粘贴到 135 编辑器或公众号后台；HTTPS 或 localhost 优先使用剪贴板 API，普通 HTTP 或接口不可用时尝试浏览器兼容复制。

局域网访问使用 Vite 输出的 Network 地址。开发代理保留页面 Host，并传递原始地址与协议；通过前端的 `/api` 访问时，不需要将每次变化的局域网 IP 加入 `ALLOWED_ORIGIN`。修改 `vite.config.js` 后需重启开发服务。前后端分属不同来源时，仍需将前端完整地址加入 `ALLOWED_ORIGIN` 并重启后端。

验证使用 `npm test` 和 `npm run build`。接口测试使用隔离的本地模型响应，不改写现有 AI 配置，也不会调用真实模型。

## 生产启动

```powershell
npm run build
npm start
```

生产启动前应先设置 `.env` 并执行构建；Express 同时提供 `dist/`、图片资源和 API。`ASSET_DIR` 用于图片持久化，默认保留七天，清理任务每日运行。`PUBLIC_BASE_URL` 配置可被公众号访问的 HTTPS 图片主机；留空时使用当前站点地址，复制结果会将非 HTTPS 图片替换为补图占位。

接口列表、错误码见 [docs/api.md](docs/api.md)。真实公众号后台粘贴回归和限制见 [docs/known-limitations.md](docs/known-limitations.md)。
